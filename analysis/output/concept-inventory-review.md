## Part 2 — transfer items (post-test only)

**TR01.** A hidden neuron with a ReLU activation has a negative weighted input (z < 0) for every training example. What happens to its incoming weights during training?

- A. They are pushed toward positive values until the neuron fires again.
- B. They grow without bound.
- C. They change randomly.
- D. They stop changing, because no gradient passes through an inactive ReLU.

**TR02.** A 3-class classifier with softmax and cross-entropy produces logits (2, 1, 0) for an example of class 1 (the first class). The gradient of the loss with respect to the logits is softmax(z) − y. Which logits have a negative gradient?

- A. Only the logit of the correct class.
- B. All three logits.
- C. Only the largest wrong logit.
- D. None of them, because the correct class already has the largest logit.

**TR03.** A convolutional layer applies 8 filters of size 3×3 to a single-channel image, with one bias per filter. How many trainable parameters does it have?

- A. 9
- B. 6 272
- C. 72
- D. 80

**TR04.** You double the mini-batch size and keep everything else the same. Which statement is correct?

- A. The parameters are updated twice as often per epoch.
- B. Each gradient estimate is less noisy, but the parameters are updated half as often per epoch.
- C. The loss function being minimised changes.
- D. Nothing changes, because the same data are seen in each epoch.
